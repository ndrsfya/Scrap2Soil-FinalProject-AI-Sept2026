# **About the Project**

Scrap2Soil is a web-based compost planning system developed to help UTP students, staff, and café operators manage organic waste more sustainably. Using a rule-based recommendation system, it helps users identify compostable materials, estimate a suitable mix of green and brown materials, get advice on common composting problems, and track their compost batches.



## **How to Run the Project**



**Step 1: Install Python and Visual Studio Code**



**Step 2: Download the Project**

* Download the Scrap2Soil project ZIP file from GitHub.
* Extract the ZIP file.
* Open Visual Studio Code.
* Click File → Open Folder.
* Select the extracted Scrap2Soil-FinalProject-AI-Sept2026-main folder.



**Step 3: Open the Terminal**

In Visual Studio Code:

* Click Terminal at the top menu.
* Select New Terminal.
* Make sure the terminal is opened inside the project folder containing app.py.



**Step 4: Install the Required Libraries**

Copy and paste the following command into the terminal:



*python -m pip install -r requirements.txt*



Press Enter and wait until the installation is completed.



**Step 5: Run the Application**

After installation, enter this command:



*python -m streamlit run app.py*



Press Enter.

The Scrap2Soil application should automatically open in your web browser.

If it does not open automatically, copy the local URL displayed in the terminal, usually:



*http://localhost:8501*

To stop running Scrap2Soil, return to the VS Code terminal and press Ctrl + C.
